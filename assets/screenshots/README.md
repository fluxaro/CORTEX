## Recording Instructions

Screenshots should be taken at:
- **Resolution:** 1920x1080 (Full HD) or 2560x1440 (2K)
- **Browser zoom:** 100%
- **Theme:** Dark mode (default)
- **Window:** Chrome or Edge — maximized

Store all screenshots as `.png` files in this directory.
